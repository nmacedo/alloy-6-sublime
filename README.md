
# Alloy 6

Syntax highlighting for the Alloy 6 modeling language in Sublime Text.

This package is generated from the [Alloy Syntax Highlighting](https://github.com/nmacedo/alloy-syntax-highlighting) project.

## Installation

Install through Package Control:

1. Open the Command Palette.
2. Select `Package Control: Install Package`.
3. Search for `Alloy 6`.

Alternatively, clone this repository into your Sublime Text Packages directory.

## Language support

- Alloy 6 syntax highlighting
- TextMate grammar with scope `source.alloy`
- `.als` files

## Development

The canonical grammar is maintained in the main repository:

https://github.com/nmacedo/alloy-syntax-highlighting

This repository contains generated distribution files. Please submit grammar changes to the main repository.
